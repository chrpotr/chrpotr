# Security Policy

This repository is public personal text (about / resume / posts).
It is not a software product and has no supported versions.

## In scope

- Secrets, credentials, or private personal data committed by mistake
- Unauthorized or malicious changes to content in this repository

## Out of scope

- Bugs in GitHub itself
- Typos, broken links, and disputes about resume or post content
- Facts or contact details already published here on purpose
- Issues on chrpotr.com or other sites
- Hypothetical problems in software that is not in this repository
- General questions, speaking requests, or other mail

## Reporting a vulnerability

Do not open a public issue, discussion, or pull request for a security
or privacy problem.

Preferred: GitHub private vulnerability reporting
(Security and quality → Advisories → Report a vulnerability).

Fallback: email grunt-dress-wiry@duck.com
That address is only for security and privacy reports. It is not a
general inbox.

Include the file path, commit SHA, what was exposed, and why it matters.

## Response

Reports are reviewed when seen. There is no SLA and no bounty.
Valid issues will be removed or corrected on the default branch.
